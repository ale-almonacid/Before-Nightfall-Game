🌲 Before Nightfall

Before Nightfall is a cozy forest survival game built with HTML, CSS, and JavaScript.

You find yourself in the forest with one goal: gather enough resources, protect your supplies from a mischievous raccoon, and build a fire before nightfall. 🌙🔥

This project was created as part of my learning process in web development and game development, giving me the opportunity to practice JavaScript, user interaction, game logic, and creating an engaging visual experience.

🎮 About the Game

The forest may look peaceful, but you don’t have much time before the sun goes down.

Explore the forest, collect the resources you need, and keep an eye on your supplies. A curious raccoon may try to interfere with your plans!

Your main objective is simple:

Gather what you need and build your fire before nightfall.

✨ Features

* 🌲 Explore a cozy forest environment
* 🪵 Gather resources (wood, dry plants and rocks) 
* 🔥 Build a fire before sunset
* 🦝 Raccoons will steal your resources, so keep gathering 
* 🎮 Interactive gameplay
* 🎵 Audio and visual elements to create an immersive atmosphere
* 💻 Built entirely with HTML, CSS, and JavaScript

🛠️ Technologies

* HTML5 — Game structure and interface
* CSS3 — Styling, layout, and visual design
* JavaScript — Game logic, interactions, and mechanics
* Audio — Sound effects and atmosphere
